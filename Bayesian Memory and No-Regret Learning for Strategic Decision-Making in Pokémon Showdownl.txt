Bayesian Memory and No-Regret Learning for Strategic Decision-Making in Pokémon Showdown
Introduction and Motivation:
Competitive Pokémon is a complex game of strategy in which players must make decisions with incomplete information. Although players can observe their opponent's Pokémon, health, and previously used moves, much of the information necessary to make optimal decisions remains hidden. A Pokémon's moveset, held item, ability, and other attributes can drastically change the outcome of a battle. Furthermore, both players select their actions simultaneously, meaning that even perfect knowledge of the current battlefield does not guarantee an optimal decision. Success therefore requires not only evaluating available actions but also anticipating an opponent's decisions, reasoning about hidden information, and adapting strategies as new information becomes available.
Recent reinforcement learning agents, such as Jaxcalibur, have demonstrated that neural networks trained through self-play can achieve exceptional performance in Pokémon Showdown. However, these systems also raise an interesting question: Can an agent become a better strategic player by explicitly reasoning about uncertainty and applying game-theoretic principles, rather than relying primarily on learned action probabilities?
This project proposes developing a Pokémon Showdown agent that combines Bayesian inference, persistent memory, and no-regret learning. Inspired by principles from imperfect-information games such as poker, the agent will maintain beliefs about its opponent's hidden information, update those beliefs throughout a battle, and use game-theoretic algorithms to select strategies that account for both uncertainty and the opponent's incentives.
Proposed Approach:
1. Bayesian Memory and Opponent Modeling
The first component of the agent will be a memory system that maintains a probability distribution over possible opposing Pokémon sets.
Rather than treating an opponent's unrevealed moves, held items, and abilities as entirely unknown, the agent will use historical data from Pokémon Showdown and competitive usage statistics to construct an initial set of beliefs. For example, if an opposing Pokémon commonly carries either a Choice Scarf or a defensive item, the agent can assign probabilities to these possibilities based on their prevalence in the relevant format.
As the battle progresses, these probabilities will be updated using Bayes' rule:
P(S | H) = P(H | S)P(S) / P(H)
Here, S represents a possible opponent set, while H represents the observations accumulated throughout the battle.
Information such as revealed moves, damage dealt, turn order, and item activations will allow the agent to gradually eliminate incompatible possibilities and adjust its beliefs about the remaining sets. Importantly, the model will consider correlations between attributes rather than treating each move and item independently.
The memory system will also attempt to capture the opponent's behavioral tendencies. Some players favor aggressive predictions, while others repeatedly choose safer switches or prioritize preserving particular Pokémon. By tracking these decisions, the agent can develop beliefs not only about what its opponent can do, but also about what its opponent is likely to choose.
This creates two interconnected sources of uncertainty: uncertainty about the opponent's available strategies and uncertainty about the opponent's preferred strategies.
2. No-Regret Learning and Mixed Strategies
The second component will use no-regret learning to determine how the agent should act given its current beliefs.
In game theory, a central concept is the Nash equilibrium, in which no player can improve their expected payoff by unilaterally changing strategies. In a game like Pokémon, however, selecting a single predictable action can allow an opponent to exploit that decision.
For example, suppose an opponent's Pokémon threatens to knock out the agent's active Pokémon. Switching to a defensive counter may appear optimal, but the opponent could anticipate that switch and use a setup move instead. Conversely, attacking immediately could punish the setup move but risk losing the Pokémon if the opponent attacks.
This interaction resembles a simultaneous-move game in which neither player necessarily benefits from always choosing the same action. Instead, the optimal strategy may involve randomizing between attacking, switching, and setting up, with probabilities determined by the relative payoffs of each action.
To approximate these strategies, the agent will employ regret matching or a related no-regret algorithm. Rather than simply choosing the action with the highest predicted value, it will iteratively evaluate how much better alternative actions would have performed against different opponent strategies.
For each decision, the algorithm will estimate the value of available actions across possible hidden opponent sets. Crucially, the agent must select one strategy based on the information it actually possesses, while recognizing that the opponent may choose different actions depending on its own private information.
Over repeated iterations, regret minimization can produce mixed strategies that approach equilibrium in the approximated game.
3. Integrating Bayesian Beliefs with Game-Theoretic Search
The most important aspect of the project will be connecting these two components.
Traditional search algorithms evaluate possible future actions and select those with favorable outcomes. However, in an imperfect-information game, the value of an action depends on both the opponent's hidden attributes and the strategy the opponent follows.
The proposed agent will therefore construct a small game-theoretic model of each decision using its current Bayesian beliefs. It will sample plausible hidden opponent sets, simulate possible action combinations, and estimate their outcomes using a battle simulator and a learned value function.
A no-regret solver will then determine a mixed strategy across these possibilities.
As new information becomes available, the Bayesian memory will update, changing the strategic game that the agent attempts to solve.
For instance, an agent might initially assign a substantial probability to an opposing Pokémon holding a Choice Scarf. Consequently, its strategy may favor defensive switches over risky attacks. After observing evidence that makes Choice Scarf unlikely, the agent may shift toward a more aggressive strategy.
This framework creates a continuous feedback loop between inference, memory, and strategic optimization.
An especially interesting extension would involve the value of information. Certain actions may be beneficial not because they maximize immediate damage, but because they reveal information that improves future decisions. Using Protect, forcing an opponent to reveal a move, or making a low-risk pivot could help distinguish between possible sets. The agent could learn to value these actions by comparing their immediate costs against the strategic advantage of reducing uncertainty.
Similarly, the agent could explore bluffing and strategic deception. By occasionally choosing actions that differ from its usual preferences, it may prevent opponents from accurately predicting its behavior. This would introduce an additional game-theoretic dimension: the agent must not only infer its opponent's beliefs but also consider how its own actions influence what the opponent believes.
Implementation and Evaluation:
The project will initially focus on Generation 9 Random Battles in Pokémon Showdown, where the random-team generation process provides a useful foundation for modeling the distribution of possible opposing sets.
Using the Pokémon Showdown battle engine and the Python poke-env interface, a reinforcement learning agent will be developed with a policy and value network trained through self-play. Bayesian belief tracking will then be incorporated to represent uncertainty about opposing teams and available actions.
A no-regret search procedure will be implemented to evaluate potential strategies using these beliefs. The agent will be compared against a standard reinforcement learning policy, a policy with Bayesian memory but no game-theoretic search, and a regret-based search agent without explicit Bayesian memory.
Performance will be evaluated through battle win rates, Elo ratings, the accuracy of hidden-set predictions, and the agent's ability to adapt to opponents with different behavioral tendencies. Additional experiments will investigate situations where strategically gathering information or randomizing between actions produces better results than greedily selecting the highest-valued move.
Desired Theoretical Outcomes and Model Objectives:
Theoretical outcomes (proof goals)
First, we aim to formalize each turn as a small Bayesian, simultaneous-move game in which the opponent knows its own hidden set while our agent acts using a probability distribution over possible sets. A central proof goal is to show that no-regret search approaches equilibrium in this approximate game, and to bound how inaccuracies in the estimated beliefs or future-state values affect strategic performance.
Target guarantee: Nash gap ≤ solver regret + belief-model error + value-estimation error.
Second, we want to study when memory is strategically sufficient. Under an appropriate model of the battle and opponent, a posterior belief over hidden sets and opponent tendencies can summarize the decision-relevant history. We would investigate bounds on the loss from compressing that belief, and construct simple games showing why ignoring correlations between moves and items, or optimizing separately for each hidden set, can lead to exploitable decisions.
Third, we hope to characterize the value of information: when is it rational to sacrifice immediate damage in order to reveal an item, test a speed assumption, or induce a revealing move? The aim is to distinguish information that changes the optimal strategy from information that merely reduces uncertainty. These are proposed theoretical goals, not claims of results already proved for full Pokémon battles.
Desired model output and competitive strengths
On each turn, the model should produce (1) a calibrated joint probability distribution over plausible opposing sets, (2) an updated estimate of the opponent’s behavioral tendencies, (3) a mixed strategy assigning probabilities to legal attacks and switches, and (4) estimated action values or regrets that help explain the chosen distribution. After every new observation, its memory and strategy would update together.
Our main competitive goal is not simply to claim the highest overall ladder Elo. We want to build an agent that is especially strong in hidden-information and prediction-heavy situations: ambiguous Choice items, unrevealed coverage moves, repeated switching mind games, and opponents whose strategies change over time. Ideally, explicit belief tracking plus no-regret search will beat comparably sized PPO-only, memory-only, and search-only baselines when given the same simulation budget.
Success would be measured by hidden-set prediction accuracy and calibration, approximate exploitability in small games with known equilibria, and head-to-head win rate and Elo against diverse Showdown opponents. The distinctive strength we want to demonstrate is robust, adaptive decision-making under uncertainty: knowing when to gather information, when to commit, and when to deliberately randomize.
Expected Outcomes and Significance:
The goal of this project is to investigate whether explicitly combining probabilistic reasoning and game-theoretic decision-making can improve the strategic capabilities of reinforcement learning agents in complex, partially observable environments.
Beyond developing a competitive Pokémon Showdown bot, the project explores a broader question: How should an intelligent agent make decisions when it has incomplete information, knows its opponent is also making strategic decisions, and can learn more about that opponent over time?
By integrating Bayesian memory with no-regret learning, the proposed system aims to move beyond reactive move selection toward a form of strategic reasoning that incorporates uncertainty, adaptation, equilibrium behavior, and the value of information.
Ultimately, the project seeks to create an agent that does not merely predict which move is most likely to win, but understands when to take risks, when to randomize, when to gather information, and when to exploit an opponent's predictable behavior.
