# Prior art scan: Bayesian set belief + per-turn equilibrium solving for Pokémon (Gen 9 Random Battles)
Scan date 2026-10-11. Tags: [verified] = I read the primary source (PDF/page/repo code) myself; [snippet-only] = only search-result text or an abstract, not read in full; [not found].
Local copies (scratch, may vanish): /private/tmp/claude-501/s/p/{pokeagent,pokechamp,metamon,pokai,radboud}.pdf/.txt

## HEADLINE
The proposal's core recipe (set-belief sampling + simultaneous-move regret-matching/Nash solve per turn, Gen 9 Random Battles) is ALREADY IMPLEMENTED at least twice in 2026: Jaxcalibur (Aug-Sep 2026, top of ladder) and Chronoquazicalar (Sep-Oct 2026 hobby repo). Equilibrium search over public belief states also exists for VGC (PokaiTrainer, Sep 2026). What is NOT done is any theory (error decomposition, posterior sufficiency, value of information, concealment) or any empirical test of equilibrium mixing in human Pokémon play.

## A. Pokémon agents

### A1. Jaxcalibur  [verified: Smogon post + write-up read; no paper, no code]
- Smogon thread "Jaxcalibur: A Gen 9 Randbats bot that reached #1 on the ladder", author handle jaxcalibur_author, posted 2026-08-28, update 2026-09-12. https://www.smogon.com/forums/threads/jaxcalibur-a-gen-9-randbats-bot-that-reached-1-on-the-ladder.3787537/
- Technical write-up (no named author/year on page; ladder run Aug 6-27): https://jaxcalibur.github.io/
- Claims: peak Elo 2557, peak GXE 95.3, about 20% of time at #1; a human (MichaelderBeste2) had GXE 95.5 and held #1 ~50%; prior best bot Foul Play peaked ~2341 Elo / 88 GXE. Code and weights NOT released ("I've decided not to release Jaxcalibur's code or model weights", 9/12). Not peer reviewed; self-reported.
- Method (write-up, quotes): 8.5M-param non-causal transformer, PPO+GAE pure self-play, battle engine reimplemented in JAX, poke-env for ladder. "Its search algorithm is a variant of pUCT designed to handle the stochastic environment"; "the Nash equilibrium is a mixed policy: there is no single best action"; "Jaxcalibur samples edges during search according to a mixture of the positive regret and network prior. This formulation makes it shift towards a regret-matching policy as the number of node visits increases." Hidden info: samples possible "worlds" (opponent sets/items) using network predictions, attributed to Foul Play's approach; "Search essentially averages over these possibilities." Auxiliary losses predict opponent item/ability/moves/Tera type and next action ("made the bot substantially stronger"). Opponent search truncated after "surprising" moves (<65% predicted likelihood) to avoid leaking hidden info (a heuristic concealment device). Depth 4, 20,480 rollouts over 32 worlds; test-time only; search worth ~100-150 Elo (author estimate).
- Implication: the proposal's "cites Jaxcalibur as a self-play RL agent" is accurate but incomplete; it is also a sim-move regret-matching + world-sampling system, i.e. the closest prior art. Belief is a learned network posterior sampled into determinized worlds, not an explicit Bayesian update from the randbats generator, and no theory is given.
- Also note an unrelated GitHub repo Xyqc/japlace ("Jaxcalibur Version Of Laplace", 2026-09-17) - appears to be a name collision/derivative, not the bot [snippet-only].

### A2. Chronoquazicalar (TurboRx)  [verified README + HF metadata; results unverified]
- https://github.com/TurboRx/Chronoquazicalar (created 2026-09-21, 2 stars), HF https://huggingface.co/TurboRx/Chronoquazicalar. MIT license.
- README: "simultaneous-move Counterfactual Regret Minimization (CFR) with polynomial Upper Confidence Trees (pUCT), and Bayesian set inference over official Pokémon Showdown Gen 9 distributions"; "CFR Regret Matching: Solves the simultaneous turn matrix at the root node for an approximate Nash Equilibrium, yielding unexploitable mixed strategies"; "Multi-Scenario Determinization ... samples candidate roles ... searches each scenario, and aggregates the resulting Nash equilibrium distributions"; "Belief State Resolution: Dynamically filters candidate roles, movepools, abilities, and Tera types as opponent moves are revealed" using randbats sets.json (509 species). Poke-env client, JAX simulator, transformer w/ opponent-action head.
- This is almost literally the proposal's pipeline (a hobby/likely heavily LLM-assisted project). I found no benchmark numbers, paper, or exploitability evaluation in the README; claims such as "unexploitable" are unsupported. Treat as proof the engineering idea is not novel, not as scientific prior art.

### A3. PokaiTrainer (Max Yu, arXiv 2608.29197v2, 28 Sep 2026)  [verified, read abstract/intro/related work]
- https://arxiv.org/abs/2608.29197. VGC (doubles), Rust engine "PokaiEngine" (~99% parity with Showdown), Student-of-Games-style CFR subgame solving over public belief states with value-network leaves, trained by self-play. "Each decision is solved by counterfactual regret minimization as a Bayesian matrix game over public belief states". Open Team Sheets only; "leave closed sheets, where the opponent's unrevealed sets must be inferred, as future work". 59% in 150 Bo3 vs ~1320 Elo field; peak 1492 Elo. "No prior Pokémon agent performs equilibrium search" (this claim is false for Jaxcalibur/Chronoquazicalar/Radboud thesis if their descriptions hold, but its related work does not cite them). "We claim no algorithmic novelty beyond the adaptations above." Also: "Deterministic play is exploitable, so optimal play requires mixing." Cites Shafiei 2009 / Lisý 2013 / Tak 2014 for DUCT being exploitable.
- Singles Gen 9 Random Battles with hidden sets (the proposal's setting) is therefore the gap relative to this paper, but belief-over-hidden-info CFR is established.

### A4. Radboud BSc thesis: "Nash equilibrium estimation in competitive Pokémon using search and supervised learning" (R. van der Heijden, supervisor J. Kwisthout)  [verified, read abstract + sec 6.3]
- https://theses.ubn.ru.nl/server/api/core/bitstreams/b8ddf389-3ed8-474d-b7b5-67f6b97868ad/content (undated in the extract; Gen 8 OU data).
- Per-turn payoff matrix from search + evaluation network, Nash computed; perfect-info only (known teams). Win rates vs Foul Play's expectiminimax: 0.173 (regular teams) / 0.618 (simplified) heuristic eval; 0.295 with learned eval. Sec 6.3 sketches (unimplemented) the incomplete-info extension: "Pokémon set model" assigning probabilities to info-states, search per n most likely info-states, "Bayes-Nash equilibrium calculation ... a single Bayes-Nash equilibrium will be calculated using n payoff matrices". That is exactly the proposal's architecture, as an unimplemented sketch.

### A5. Foul Play (Patrick Mariglia)  [verified: README, code, PokéAgent paper App. E.1.2]
- https://github.com/pmariglia/showdown redirects to https://github.com/pmariglia/foul-play ; engine https://github.com/pmariglia/poke-engine (Rust; README lists "Expectiminimax" subcommand; MCTS in newer code).
- PokéAgent paper (arXiv 2603.15563, App. E.1.2): "root-parallelized Monte Carlo Tree Search (MCTS) with the Decoupled Upper Confidence Bound applied to Trees (DUCT) formula to handle simultaneous move selection"; won the Gen 9 OU track "50-14 finals"; >90% GXE in Gen 9 Random Battles, peak rating 2341; "Set prediction is critical ... By sampling from likelihood-weighted distributions of possible opponent configurations during search".
- Code (fp/search/random_battles.py, fp/search/main.py, spot-read): per search it deep-copies the battle `num_battles` times, samples each opponent Pokémon's full set with `random.choices(..., weights=[s.pkmn_set.count ...])` from remaining-consistent sets (filtered by revealed info), runs an independent MCTS per sample, sums visit-fraction policies weighted by sample chance, keeps moves with mass >= 75% of the top move and samples from them with `random.choices`. So: set sampling from count-weighted data = yes (this is determinization/PIMC); simultaneous moves = DUCT in MCTS (not a true equilibrium solve); final randomization is an ad-hoc mixing of top moves, not a Nash mix. PokaiTrainer's related work says Foul Play "selects each side's action by independent UCB1" and "fixes one spread per search".

### A6. PokéChamp (Karten, Nguyen, Jin; arXiv 2503.04094; ICML 2025, PMLR 267)  [verified, read]
- https://arxiv.org/abs/2503.04094. LLM-augmented minimax: LLM does action sampling, opponent modeling, value estimation. Gen 9 OU and Gen 8 Random Battles. Hidden info: "we leverage the statistical data from Pokemon showdown, including Pokemon move pools, EV spreads, item usage" plus LLM guesses of opp A/D stats. Search is max-min, not mixed. Conclusion quote: "The objective of our framework lies at the intersection of imitation learning, best response estimation, and Nash equilibrium approximation ... the exact relationship between our method and the optimal best response remains an open question". Formalizes Nash/minimax theorem in sec 3. Reported: 76% vs best LLM bot, 84% vs best rule-based bot (Gen 9 OU), projected Elo 1300-1500 [abstract-level, snippet-only for numbers]. Dataset of >3M games.

### A7. PokeLLMon (Hu, Huang, Liu; arXiv 2402.01118, 2024)  [snippet-only for numbers; paper not read]
- https://arxiv.org/abs/2402.01118. LLM agent with in-context RL, knowledge-augmented generation, consistent action generation. 49% ladder / 56% invited battles vs humans. No equilibrium or belief machinery.

### A8. Metamon (Grigsby, Xie, Sasek, Zheng, Zhu; arXiv 2504.04395; RLC 2025/RLJ vol 6)  [verified, read intro/related work]
- https://arxiv.org/abs/2504.04395 ; site https://metamon.tech ; code https://github.com/UT-Austin-RPL/metamon. Offline RL with long-context transformers on reconstructed human replays; "without explicit search of any kind"; Gen 1-4 OU emphasis (not Gen 9 randbats); top 10% of ladder. Hidden-set inference is implicit in memory ("using model-free RL and long-term memory to infer their opponent's team"), framed as Bayesian-RL/POMDP. Notes decisions are simultaneous but no equilibrium reasoning (grep: only a mention at line 107 and DeepNash/search in related work).

### A9. PokéAgent Challenge (Karten et al., arXiv 2603.15563; NeurIPS 2025 competition track)  [verified partially: abstract, Sec 5, App E read]
- https://arxiv.org/abs/2603.15563 ; https://pokeagentchallenge.com. Two tracks: competitive battling (Gen 9 OU, Gen 1 OU) and RPG speedrunning. 100+ teams. Battling: FoulPlay won Gen 9 OU ("outperformed private baselines by all metrics"); in Gen 1 OU, 4thLesson separated from public baselines and PA-Agent (iterative offline RL) placed first among participants "by a wide margin" [as worded in text; exact final ranking not verified]. "all top-performing submissions employed RL or search-based methods rather than pure LLM approaches". Speedrun winner: Heatz (Scripted Policy Distillation, 40:13). No Gen 9 randbats track; no equilibrium-based entry reported.

## B. Game-theory background (citation details)
All below: bibliographic details [snippet-only] unless noted; none read in full. Verify page numbers before citing.
- DeepStack: Moravčík et al., "DeepStack: Expert-level artificial intelligence in heads-up no-limit poker", Science 356(6337), 2017; arXiv 1701.01724 (continual re-solving). 
- Libratus safe/nested subgame solving: Brown & Sandholm, "Safe and Nested Subgame Solving for Imperfect-Information Games", NeurIPS 2017, arXiv 1705.02955. Key quote (search summary of the abstract/intro): imperfect-information games cannot be solved by decomposing into independent subgames; "all decisions must consider the strategy of the game as a whole." This is the soundness warning: re-solving a subgame with a fixed (e.g. posterior-sampled) belief without the opponent's alternative-play constraints can be exploitable. Also Brown & Sandholm, "Superhuman AI for heads-up no-limit poker: Libratus beats top professionals", Science 2018.
- ReBeL: Brown, Bakhtin, Lerer, Gong, NeurIPS 2020, arXiv 2007.13544 (public belief states, "provably converges to a Nash equilibrium in any two-player zero-sum game").
- Student of Games: Schmid et al., Science Advances 2023, doi 10.1126/sciadv.adg3256, arXiv 2112.03178 (growing-tree CFR).
- PIMC/strategy fusion: Frank & Basin, "Search in games with incomplete information: a case study using Bridge card play", Artificial Intelligence 100 (1998) [dates vary across records]; Long, Sturtevant, Buro, Furtak, "Understanding the Success of Perfect Information Monte Carlo Sampling in Game Tree Search", AAAI 2010, pp. 134-140, https://ojs.aaai.org/index.php/AAAI/article/view/7562 (non-locality; why PIMC works in practice). Note Foul Play and Jaxcalibur's world-sampling are PIMC-style.
- SM-MCTS: Lanctot, Lisý, Winands, "Monte Carlo Tree Search in Simultaneous Move Games with Applications to Goofspiel", CGW 2013 (CCIS 408, pp. 28-43), doi 10.1007/978-3-319-05428-5_3 (regret matching / OOS best, all less exploitable than UCT). Lisý, Kovařík, Lanctot, Bošanský, "Convergence of Monte Carlo Tree Search in Simultaneous Move Games", NeurIPS 2013, arXiv 1310.8613; Lisý et al. "Analysis of Hannan consistent selection for MCTS in simultaneous move games", arXiv 1509.00149 (v. 1804.09045 also surfaced). Shafiei et al. 2009 and Tak et al. 2014 (cited via PokaiTrainer) on DUCT exploitability.
- Double oracle: Bošanský, Lisý, Lanctot, Čermák, Winands, "Algorithms for computing strategies in two-player simultaneous move games", Artificial Intelligence 237 (2016) 1-40; earlier Bošanský et al., IJCAI 2013 "Using Double-Oracle Method and Serialized Alpha-Beta Search for Pruning in Simultaneous Move Games".
- Aumann & Maschler, Repeated Games with Incomplete Information, MIT Press 1995 (book; cav u for the informed player's value; no-revelation = play non-revealing). Mertens & Zamir (limit value via Cav/Vex). I did not retrieve an explicit statement of cav u.
- Value of information in zero-sum games: Gossner & Mertens, "The Value of Information in Zero-Sum Games" (CREST working paper 2020-19 listing; the manuscript dates to ~2001 and is unpublished) https://ideas.repec.org/p/crs/wpaper/2020-19.html [existence verified, contents NOT read; I cannot confirm from this scan that it states "information never hurts"]. Caveat for your proposal: the classical fact is that more information for a player (in the Blackwell sense, when the information is private and the other player knows the structure) cannot lower that player's value in a zero-sum game, but information given to BOTH players can help or hurt either; check Gossner-Mertens directly. Related: Gensbittel-Peski-Renault, "Value-based distance between information structures", Theoretical Economics 2022 [snippet-only].
- Opponent exploitation: Ganzfried & Sandholm, "Safe Opponent Exploitation", ACM TEAC 2015 (special issue on EC-12) [snippet-only; abstract not retrieved]; Johanson, Zinkevich, Bowling, "Computing Robust Counter-Strategies" (restricted Nash response), NIPS 2007 (proceedings vol. 20; pages vary across records), https://proceedings.neurips.cc/paper/2007/hash/6e7b33fdea3adc80ebd648fffb665bb8-Abstract.html [abstract verified via snippet]; Southey et al., "Bayes' Bluff: Opponent Modelling in Poker", UAI 2005, pp. 550-558 [bibliographic entry only]; Ganzfried & Sandholm, "Bayesian Opponent Exploitation in Imperfect-Information Games", arXiv 1603.03491 [title only].

## D. Empirical tests of minimax play in natural data (added at coordinator request)
Tests: (i) equal win rates across the strategies a player uses; (ii) serial independence of choices.
- Walker & Wooders, "Minimax Play at Wimbledon", AER 91(5):1521-1538, 2001, doi 10.1257/aer.91.5.1521. Tennis serve direction. Win rates equal across serve directions (consistent with minimax) but players switch too often (serial dependence). [snippet-only]
- Chiappori, Levitt, Groseclose, "Testing Mixed-Strategy Equilibria When Players Are Heterogeneous: The Case of Penalty Kicks in Soccer", AER 92(4):1138-1151, 2002, doi 10.1257/00028280260344678; PDF https://pricetheory.uchicago.edu/levitt/Papers/ChiapporiGrosecloseLevitt2002.pdf [snippet-only; abstract not read]. Palacios-Huerta, "Professionals Play Minimax", Rev. Econ. Studies 70(2):395-415, 2003, doi 10.1111/1467-937X.00249 [snippet: "(i) winning probabilities are statistically identical across strategies ... (ii) players' choices are serially independent"].
- Follow-ups [snippet-only]: Hsu, Huang, Tang, AER 97(1):517-523, 2007 (broader tennis data); Gauriot, Page, Wooders, "Nash at Wimbledon: Evidence from Half a Million Serves" (https://www.johnwooders.com/papers/NashAtWimbledon.pdf; win-rate conformity strong for men, less so for women, better for higher-ranked); Wooders, Econometrica 2010 re-analysis of Palacios-Huerta-Volij lab data (professionals deviate); Levitt-List-Reiley (NBER w15609) and Anderson "Disequilibrium play in tennis" (serial correlation can arise from muscle memory); O'Neill 1987 / Brown-Rosenthal 1990 (lab card game rejects minimax, serial correlation). Dohmen & Sonnabend 2018, "Further Field Evidence for Minimax Play" (J. Sports Economics) [title only].
- Online games / esports / poker: [not found] in this scan. No hit on a field-data minimax test for StarCraft, League, fighting games, or poker (searches returned only tennis/soccer/lab).
- Pokémon specifically: [not found]. No study of whether Showdown players' switch/stay or attack/protect frequencies match equilibrium mixing. Closest: community tools (Pokémon Battle Predictor Smogon extension predicting switches from replays [snippet-only]), Cornell toy-model blogs (A13), and PokaiTrainer's assertion (no empirical test) that optimal play requires mixing. This looks open and is checkable with Metamon's raw/parsed replay datasets (turn-level actions with visible outcomes).

## NOVELTY VERDICT
Already done: (1) Sim-move search with regret-matching-style selection plus sampled opponent-world determinization in Gen 9 Random Battles (Jaxcalibur, self-reported #1, closed source, no theory; Chronoquazicalar, hobby repo claiming CFR root matrix + Bayesian role filtering over pkmn/randbats data, no evaluation). (2) Set-sampling from count-weighted data inside simultaneous-move MCTS (Foul Play, strong open-source baseline, GXE >90 in Gen 9 randbats). (3) Per-turn Nash on a payoff matrix for Pokémon (Radboud thesis, perfect info) with an unimplemented Bayes-Nash sketch that matches the proposal's architecture. (4) CFR over public belief states with a Bayesian matrix game for Pokémon VGC (PokaiTrainer, open team sheets). (5) Opponent-hidden-info/action prediction heads (Jaxcalibur, Chronoquazicalar), and LLM opponent models (PokéChamp). So "Bayesian belief + per-turn equilibrium solver" is not a novel system claim; claiming it as the contribution would be a mistake, and "no prior Pokémon agent performs equilibrium search" (PokaiTrainer's claim) should not be repeated.
Looks open: (a) any formal result: the error decomposition "Nash gap <= solver regret + belief error + value error" for per-turn re-solving with a fixed posterior (known pitfalls: Brown-Sandholm unsound independent subgame solving, PIMC strategy fusion/non-locality; none of the Pokémon systems analyze this); conditions under which a posterior is a sufficient memory (ReBeL's PBS is the closest general statement, but the opponent's range matters, not just the agent's posterior); (b) value of information / information-revealing and concealment actions in Pokémon (Jaxcalibur's "<65% surprising action" truncation is a heuristic nod, with no analysis); (c) controlled comparison of an explicit Bayesian posterior from the randbats generator vs a learned posterior vs count-sampled determinization, with exploitability measured (no one reports exploitability or best-response value for any Pokémon agent; PokaiTrainer does a limited "informed best response" test in Sec 5.2, not read in detail); (d) empirical tests of equilibrium mixing in human Showdown play. Practical risk: the bar for "strong" in Gen 9 randbats is now Foul Play ~2341 Elo and Jaxcalibur ~2557 (closed); a course project should position itself as an analyzable, exploitability-measured small system and theory, not as a ladder-strength claim.
